## How to read future-feature claims

Treat an item as confirmed only when an official post clearly identifies it as planned. Community wishlists, data-mined references, translations, and speculative release windows are useful leads, not a roadmap. If a later official announcement adds milestones, this page should be updated with the source date and the exact scope rather than silently replacing the previous status.
