## How to use this information

The counts establish that Sephiria has a broad build system, but they are not enough to publish a trustworthy optimal-path guide. A proper tree map needs the weapon branch, node name, effect, cost, prerequisite, game version, and a reproducible source for every entry.

## Where to verify updates

Check the [official Steam store page](https://store.steampowered.com/app/2436940/Sephiria/) and [Steam update history](https://store.steampowered.com/news/app/2436940) for changes. Patch notes may add, remove, or rebalance items, so a future detailed tree should always show the patch or game version it covers.
